## 4. Scrapy Item 定义 (items.py)

### 4.1 统一 Item

```python
@dataclass
class CrawlerItem:
    # ── 必填字段 ──
    source_type: str           # "domestic" | "overseas"
    source_name: str           # "wechat_chengdu" | "producthunt" 等，对应 config/sources.py 的 key
    lang: str                  # "zh" | "en" | "ja" 等
    title: str                 # 文章标题
    content: str               # 清洗后的纯文本正文
    original_url: str          # 原文链接

    # ── 可选字段 ──
    summary: str = ""          # 导语/摘要（原文自带）
    author: str = ""           # 作者
    created_at: str = ""       # 原文发布时间，ISO格式 "2026-06-08T10:00:00Z"
    location: str = ""         # 位置信息（国内源用）
    price: float = 0.0         # 价格（优惠类用）
    validity_end: str = ""     # 有效期截止（优惠类用）
    tags: list = field(default_factory=list)  # 标签列表
    images: list = field(default_factory=list)  # 图片URL列表（发帖用）
```

### 4.2 Spider 输出契约

每个 spider 的 `parse()` 方法必须 `yield CrawlerItem(...)`，不允许直接 yield dict。

## 5. 数据清洗规则 (pipelines.py)

| 清洗步骤 | 规则 |
|---------|------|
| HTML 标签剥离 | 使用 `parsel` 或 `beautifulsoup` 去除所有 HTML 标签 |
| 空白压缩 | 多个空白/换行压缩为单个空格 |
| URL 标准化 | 相对路径转为绝对路径 |
| 长度截断 | title ≤ 300 字，content ≤ 50000 字 |
| 编码统一 | 统一为 UTF-8 |
| 敏感词过滤 | 命中黑名单关键词的直接丢弃 |
| 去重检查 | 根据 original_url 检查是否已推送过 |

## 6. 推送接口契约 (push_client.py → Backend)

### 6.1 后端已实现的端点


### 6.2 PushClient 接口

```python
class PushClient:
    """推送到后端的 HTTP 客户端"""

    def __init__(self, base_url: str = "http://localhost:8080/api/crawler"):
        ...

    def push_one(self, item: CrawlerItem) -> PushResult:
        """
        推送单条内容。
        POST /push
        Request:
        {
            "sourceType": "domestic|overseas",
            "lang": "zh",
            "sourceName": "wechat_chengdu",
            "content": {
                "title": "...",
                "content": "...",
                "originalUrl": "...",
                "location": "...",        # 国内源
                "price": 25.00,            # 优惠类
                "validityEnd": "...",       # 优惠类
                "tags": ["tag1", "tag2"],   # 海外源
                "author": "...",
                "createdAt": "..."
            }
        }
        Response 200:
        {
            "type": "domestic|overseas",
            "deal": { ... } | "content": { ... }
        }
        Response 400:
        { "error": "content is required" }
        Response 500:
        { "error": "Processing failed: ..." }
        """

    def push_bulk(self, items: list[CrawlerItem]) -> BulkPushResult:
        """
        批量推送多条。
        POST /push-bulk
        Response:
        { "total": N, "success": N, "failed": N }
        """
```

### 6.3 推送策略

| 策略 | 说明 |
|------|------|
| 单条推送 | 实时性高的源（抖音、论坛）逐条推送 |
| 批量推送 | 批量源（公众号集合）攒够 10 条或每 5 分钟批量推一次 |
| 失败重试 | 指数退避：1s → 2s → 4s → 8s → 16s，最多 5 次 |
| 失败降级 | 重试耗尽后写入本地 `failed_queue.json`，下次启动时重试 |

### 6.4 PushResult 定义

```python
@dataclass
class PushResult:
    success: bool
    status_code: int
    message: str = ""
    item_id: str = ""

@dataclass
class BulkPushResult:
    total: int
    success: int
    failed: int
    results: list[PushResult] = field(default_factory=list)
```

## 9. 错误处理与日志

| 异常类型 | 处理方式 |
|---------|---------|
| HTTP 错误 (4xx/5xx) | 记录日志，重试最多 3 次 |
| 解析错误 | 跳过当前 item，记录 raw HTML 到 `debug/` 目录 |
| 推送失败 | 见 6.3 推送策略 |
| 调度器异常 | 邮件/日志告警，自动重启 |

日志格式：
```
[2026-06-08 10:00:00] [wechat_chengdu] INFO  开始爬取，种子数: 5

[2026-06-08 10:00:07] [wechat_chengdu] ERROR 解析失败: https://... (跳过)
```

## 11. 爬虫 → 后端 端到端数据流

```
爬虫 Spider (parse)
    │ yield CrawlerItem{...}
    ▼
Pipeline (process_item)
    │ 1. clean()         — HTML剥离、空白压缩、编码统一
    │ 2. dedup()          — 按 original_url 去重
    │ 3. validate()       — 必填字段检查
    │ 4. classify_tags()  — 根据关键词自动打标签
    ▼
PushClient.push_one(item)  /  push_bulk(items)
    │ POST /api/crawler/push
    ▼
CrawlerController (Spring Boot)
    │ sourceType=domestic  →  ContentService.processAndSave()
    │ sourceType=overseas  →  GlobalService.processAndSave()
    ▼
AiService.classify() + [overseas] AiService.translate()
    ▼
MySQL (deal / global_content)
```

## 12. 多智能体任务分配

| Agent | 负责文件 | 说明 |
|-------|---------|------|
| **Agent A** | `spiders/domestic/` 下 4 个 spider | 成都公众号 + 抖音 + 论坛 + 政府 |

### 自审要求

每个 Agent 写完代码后，自审以下内容：

- [ ] 所有字段名、类型与本文档一致
- [ ] Spider 的 parse() 产出 CrawlerItem 而非 dict
- [ ] PushClient 的 HTTP 请求格式与后端契约一致
- [ ] 所有异常路径有 try-catch
- [ ] 敏感信息（API Key）从环境变量读取
- [ ] 没有硬编码 URL 或 token
- [ ] 中文注释清晰
